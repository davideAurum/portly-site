# portly-site

The public home page, privacy policy and terms of service of
[Portly](https://github.com/davideAurum/Portly), served at
<https://davideaurum.github.io/portly-site/>. The Google and Microsoft consent screens and
Portly's footer link here.

The source is the `site/` folder of the Portly repository; this repository is a copy of it. Edit
the pages there, then copy them here.
